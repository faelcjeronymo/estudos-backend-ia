Desafio Final
Construa o agente interno que você sempre quis. Um sistema real que conecta Claude, MCP, GitHub, Outline e Linear — e que você consegue explicar, manter e expandir sozinho. Esse projeto é a prova de que você absorveu as duas trilhas.
checklist de requisitos
Agente funcional com Claude via API
O agente recebe uma pergunta e responde usando o contexto do projeto. Sem alucinação sobre dados internos.
RAG conectado ao Outline (documentação interna)
O agente busca na sua base de conhecimento antes de responder. Documentos indexados e atualizados.
Integração MCP com GitHub
O agente consegue consultar PRs, issues e commits do repositório via MCP.
Integração com Linear (tasks e projetos)
O agente consegue criar, consultar e atualizar tasks no Linear.
Suite de testes cobrindo os fluxos principais (TDD)
Não é vibe code. Cada integração tem teste. CI roda antes de qualquer merge.
Rodando em cloud (AWS) com deploy automatizado
GitHub Actions faz o deploy. Você não sobe na mão.
CLAUDE.md documentando a arquitetura e as regras do agente
Qualquer outro dev (ou IA) consegue entender o projeto lendo esse arquivo.
Segurança revisada: sem credenciais expostas, auth implementada
Passa pelo checklist OWASP. Nenhuma vulnerabilidade óbvia.
